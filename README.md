PROJECT OVERVIEW
THIS PROJECT FOCUSES ON UTILIZING CISCO PACKET TRACER TO CONSTRUCT, CONFIGURE, AND SIMULATE A COMPUTER NETWORK.
THE PROJECT'S GOAL IS TO SHOW HOW VARIOUS NETWORKING DEVICES CAN BE JOINED TO FORM A SCALABLE, DEPENDABLE, AND FUNCTIONAL NETWORK.
A ACTUAL ORGANIZATIONAL NETWORK MADE UP OF ROUTERS, SWITCHES, PCs, SERVERS AND OTHER NETWORK COMPONENTS WILL BE REPRESENTED BY THE SUGGESTED NETWORK
TOPOLOGY.THE NETWROK WILL BE SET UP USING THE PROPER NETWROKING PRINCIPLES INCLUDING IP ADDRESSING, SUBNETTING, ROUTING, VLANs AND NETWORK SECURITY TO ENABLE
DEVICES TO COMMUNICATE TO ONE ANOTHER.
